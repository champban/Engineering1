# Object Studio Acceptance Checklist

- Open the Object Studio from the Phase 1 workspace.
- Select each demo object in the Outliner.
- Test move, rotate, and scale gizmos.
- Add box, cylinder, sphere, and plane primitives.
- Apply standard materials and upload a texture image.
- Change colour, roughness, metalness, opacity, texture repeat, rotation, and wrapping.
- Switch between isometric, front, right, and top camera views.
- Toggle perspective and orthographic projection.
- Use the tape measure by selecting two points.
- Change lighting presets and grid snapping.
- Export the Object Studio document as JSON.

Advanced face topology, Push/Pull, UV seam editing, section planes, and boolean solids remain future milestones.
