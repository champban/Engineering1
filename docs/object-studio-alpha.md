# Object Studio Alpha

This increment adds a full-screen engineering object editor with a large Three.js viewport, object Outliner, transform gizmos, primitive creation, surface materials, texture upload, camera presets, grid snapping, measurements, scene lighting, local persistence, and JSON export.

Working capabilities:

- Select, move, rotate, scale, orbit, pan, paint-surface selection, and two-point measurement.
- Create box, cylinder, sphere, and plane primitives.
- Edit object dimensions, position, rotation, scale, visibility, and lock state.
- Apply standard engineering material presets.
- Edit colour, metalness, roughness, opacity, texture repeat, texture rotation, and wrapping.
- Upload and remove texture images for object skin surfaces.
- Switch between isometric, front, right, and top views.
- Use perspective or orthographic projection.
- Use Studio, Sunlight, Warehouse, and Inspection lighting presets.
- Apply calibrated dimensions and material names back to linked Gallery assets.

The editor is a major improvement over the previous compact Gallery preview, but it is not yet equivalent to the complete SketchUp topology toolset. Face-level selection, Push/Pull, Offset, editable edges, UV seam editing, section planes, and boolean solids remain visible as planned capabilities and are not represented as complete.
